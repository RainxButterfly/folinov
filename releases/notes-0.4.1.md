# Folinov Console 0.4.1

[Features and compatibility](features-0.4.1.md)

- 公开文档和表格支持拥有者独立配置修改、删除、指定成员授权与留言区开关
- 新增项目文件夹、多级目录、目录重命名和批量归档，保留原有协作权限
- 普通文档增加字体字号、文字颜色、图片、查找替换、HTML 导出和打印/PDF，修复 Markdown 导出结构
- 智能表格增加统计概览、分组统计图、批量修改、组合筛选和日历日期字段选择
- 完善导图多工作表与游离分支导入、长标题换行、配色、适应画布与查找
- 文档、表格和导图增加版本历史预览、命名、导出和恢复，恢复前备份当前内容
- 新增保存冲突保护、本地失败草稿恢复、另存私有副本和备份文件导入

Android versionCode 16. 签名与旧版一致，可覆盖升级。
