# Folinov Console 0.4.4

[Features and compatibility](features-0.4.4.md)

- 修复已有删除文件夹时，归档和拖动出现字段 0 读取失败；支持文件夹内连续移动
- 新建文档、模板、普通/智能表格和导入内容与当前文件夹一次提交，归档失败自动回滚
- 文档表格边缘悬停出现加号，点击插入行列；表格前后可直接添加文字段落
- 右上角 Markdown 识别提示，确认后转换，支持撤销；取消、关闭或等待 10 秒撤下提示
- 打印改为独立打印机图标，原生品牌 PDF 已实际导出并检查无 localhost、导航和默认页脚
- 补齐关闭留言区的后端权限校验；Windows 与 Android 使用真实数据库驱动完成回归验收

Android versionCode 19. 签名与旧版一致，可覆盖升级。
