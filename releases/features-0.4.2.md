# Folinov Console 0.4.2

Windows 与 Android 同步更新，Android versionCode 为 17，正式签名沿用旧版。

- 修复 Windows 打开文档、表格、导图或检查历史版本时可能直接闪退的问题。原因是 MySQL 对 `COALESCE(BIGINT UNSIGNED, 0)` 返回 `DECIMAL(20,0)`，旧代码按无符号整数读取并触发进程终止。现明确 CAST 为 UNSIGNED，改用可失败的数据读取，并隔离单次 RPC 异常。已用本地 MySQL 协议服务器复现原始驱动错误并验证修复。
- 桌面数据库连接池改为每个客户端最多一个连接，空闲十秒后回收；连接失败在界面提示，不作为退出程序的理由。
- 文档、表格列表改为桌面式文件夹和文件卡片。双击文件夹进入，面包屑与返回上级按钮导航；可将自己创建的文件直接拖入文件夹，也可拖到面包屑移回上级。触屏支持点击进入。
- 文件夹右键提供打开、重命名、删除到回收站。删除前从服务端统计包含的内容数量；包含锁定内容时阻止删除。只整理自己创建的内容，不会删除其他成员的作品。
- 文档和表格新增删除锁定，只有拥有者或内容管理员可锁定/解锁；锁定后单项删除和整个文件夹删除均被服务端阻止。
- 用户删除操作统一进入回收站，数据库保留业务行、正文、权限、历史、评论、任务关联及作者记录。适用于文档、表格、导图、任务、文件链接、公告、日程、讨论、任务列和成员。成员删除会撤销会话并停用账号，管理员可恢复；至少保留一名管理员。
- 回收站提供恢复，整个文件夹及其此次删除的内容一起恢复。数据库中保留内容不等于业务列表继续显示：正常列表、搜索、资料卡及直接打开入口会过滤已删除项目。回收站不提供彻底删除按钮。任务列有任务时先移动任务再删除。
- 智能表格删除记录、字段保留原值和坐标，提供已删除内容恢复；思维导图删除主题保留子树，可恢复。普通表格结构删除前强制保存完整历史快照；历史版本超出显示数量后归档保留数据库快照，不再物理清理。
- 打印/PDF 和 HTML 导出使用独立的工作室版式：左上角 Logo 与 Folinov 工作室名称，中间文档标题和正文，无应用侧栏、工具栏、批注栏或导航。Windows 使用 WebView2 原生 PDF 导出并显式关闭默认页眉页脚，因此不会打印 localhost、页面地址、浏览器标题或默认页码。生成 PDF 后打开系统 PDF 阅读器，可从阅读器打印。Android 使用系统打印适配器。

新增 `recycle_bin` 表；其余已有业务表无需改动即可保留删除的数据。升级后客户端首次访问按现有机制建表，发布前亦核对真实数据库结构。

数据保留意味着数据库占用可能随内容与历史增长，现有容量提示仍有效。回收站恢复重新显示原始记录；历史归档继续保留快照。认证会话失效清理、本机缓存清理、用户主动编辑正文和修改成员/任务关联不属于业务删除回收站操作。

浏览器回归覆盖文件夹导航、拖拽、右键重命名、计数确认、逻辑删除、回收站恢复、锁定、独立打印内容及已有版本历史功能。实际 Windows 打印机和 Android 真机安装体验仍需设备验证；浏览器 PDF 检查不冒充实体打印机测试。
