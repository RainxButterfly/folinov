# Folinov Console 0.4.5

本次为时间显示与逻辑删除修复，Windows 和 Android 同步更新。

- 修复创建、保存文档后显示约八小时前的问题。数据库连接和写入时间统一为北京时间，前端正确解析数据库时间，并兼容带时区的时间字符串。
- 修复跨时区客户端的相对时间显示；纯日期保留原日期，日程输入转换为数据库时间。
- 文档、表格、思维导图、任务、文件、公告、日程、讨论、成员、任务状态、文件夹和历史版本补齐 `deleted` 字段：正常为 0，删除为 1，恢复为 0。
- 单条删除、文件夹批量删除、恢复及历史保留同步维护删除标志，保留正文、评论、权限与原创建和更新时间。
- 已迁移数据库增加兼容触发器，旧客户端通过回收站删除和恢复时，也同步维护业务表删除标志。
- 修复他人删除后列表和本机副本仍显示的问题：列表每15秒刷新，并在切回应用、网络恢复时刷新；已删除或失去权限的内容不再从缓存打开，未保存修改保留为独立草稿。
- 回收站保留30天，正常使用时定期清理到期条目，到期后禁止恢复。清理回收站元数据继续保留业务表的逻辑删除标志，不会让内容重新出现。

Android versionCode 为 20，使用原正式签名，可覆盖升级。历史记录曾混用时区，本次未对缺少来源依据的历史时间做批量加减。

本次完成时区回归、真实桌面 SQLx/MySQL 接口、已编译安卓 JDBC/MySQL 工作流及构建检查。检查范围及结果以发布清单为准；实体设备安装、系统安装器交互和真实打印机未在本次自动化验收。
