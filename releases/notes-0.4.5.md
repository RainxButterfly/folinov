# Folinov Console 0.4.5

[Features and compatibility](features-0.4.5.md)

- 修复文档刚创建或保存后显示约八小时前：统一北京时间数据库连接、写入及前端时间解析
- 文档、表格、任务等相关业务表补齐 deleted：正常 0、删除 1、恢复 0
- 单条和文件夹批量删除恢复同步维护删除标志，保留正文、评论、权限与原时间
- 兼容旧客户端的回收站操作，历史版本保留同步维护删除状态
- 修复他人删除后本机缓存继续显示：自动刷新列表，确认删除后移除副本并保留未保存草稿
- 回收站保留30天，到期清理且不可恢复，逻辑删除状态持续保留
- Windows 与 Android 同步修复；安卓正式签名保持一致，可覆盖升级

Android versionCode 20. 签名与旧版一致，可覆盖升级。
