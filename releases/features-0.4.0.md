# 0.4.0 成员组、智能表格与思维导图

电脑和 Android 共用完整工作台，新功能在两端均可使用。

## 成员组与资料

「沟通 → 成员组」向所有登录成员开放，支持按名字、职位搜索，按职位分组浏览。点击成员卡片或消息、讨论、任务执行者、文档作者头像可打开公开资料。资料只包含名字、头像、职位和该成员创建的团队公开文档、表格；即使管理员打开资料卡也不会列出私有内容。登录账号、权限、最近登录时间等仅在管理页面出现。

管理员可从成员组进入「成员管理」，也可从手机「更多」进入。手机操作按钮常显，支持新增、查看、编辑、重置密码、停用、恢复和删除。账号有作品、编辑记录、消息等协作历史时拒绝物理删除，使用停用可立即撤销登录并保留作者记录；没有协作历史的账号可以删除。禁止删除自己，并保留至少一名管理员。受托成员管理者不可以删除账号或授予管理员身份。

## 智能表格

表格列表可直接新建智能表格。现有表格可切换到智能表格，第一行作为字段名。

- 字段支持文本、数字、日期、单选、多选、勾选、成员、HTTP/HTTPS 链接和公式，可配置必填。选项由字段设置维护。
- 点击字段名编辑类型、名称、选项、必填或删除字段。字段类型变更保留原始值，已有值应按新类型检查。
- 新增记录使用完整表单，支持编辑、复制、多选批量删除。删除记录不移动其他行，批注仍对应原坐标。成员字段保存显示名字；成员以后改名时旧记录不会自动重写。
- 保存最多 20 个视图，每个视图保留名称、布局、多条件筛选、排序、分组和隐藏字段。设置保存在数据库，可跨设备查看。
- 布局包括表格、分组看板、画廊和月历。看板按所选字段分栏，文本、单选、成员字段支持鼠标拖动卡片改变分组；手机可打开卡片编辑该字段。月历使用第一个日期字段，可切换月份；无日期记录列在下方。
- 数字字段统计当前筛选结果的合计。公式字段使用 `{row}` 代表原始行号，如 `=B{row}*C{row}`。

普通表格增加撤销 / 重做、区域复制、TSV 区域粘贴、清空选区和分页。Shift+点击选择区域，工具栏可复制或清空选区；手机可使用复制、粘贴按钮。插删行列调整普通公式引用和智能字段 / 视图索引。批注仍绑定单元格地址；结构改变后应核对原始引用。

公式支持 SUM、AVERAGE、MIN、MAX、COUNT、COUNTA、COUNTIF、SUMIF、ROUND、ABS、IF、IFERROR、AND、OR、NOT、CONCAT、LEN、UPPER、LOWER、TRIM、LEFT、RIGHT、TODAY 和常用运算。IF 只计算选中的分支，循环引用与已删除引用分别显示错误。

## 思维导图

「协作 → 思维导图」支持新建、搜索、编辑、删除、团队 / 私有可见范围、自动保存和本机副本。可以增加子主题或同级主题、修改文字 / 备注 / 颜色、更换父主题、折叠展开、缩放、撤销和重做。键盘支持 Tab 添加子主题、Enter 添加同级主题、Delete 删除主题；触屏可以使用工具栏。

导出支持 JSON、Markdown 大纲和 SVG 图片。JSON 保留节点文字、结构、备注、颜色与折叠状态；Markdown 保存文字和结构。导图最多 1000 个节点、17 层、256 KB。

## 导入

| 内容 | 支持格式 | 行为 |
| --- | --- | --- |
| 文档 | DOCX、Markdown、TXT、HTML | 从文档列表创建新文档，也可在编辑器导入替换；导入 HTML 会清理脚本和事件属性 |
| 表格 | XLSX、XLS、CSV、ODS | 选择工作表导入；保留单元格公式与值，不再静默截断；支持导出 XLSX |
| 思维导图 | XMind JSON/XML 格式、FreeMind `.mm`、JSON、Markdown/TXT 大纲 | 导入树形主题；XMind 使用第一个画布 |

新导入文档和表格默认仅自己可见，可自行切换到团队可见。思维导图按新建的团队可见规则创建。安卓从系统文件提供器读取真实文件名、大小，支持没有扩展名的内容 URI。

单个导入文件最多 12 MB；转换后的文档最多 1 MB；表格最多 1000 行、100 列、512 KB。超限会提示拆分，不会声称成功导入完整文件。

## 兼容范围

这是常用智能表格能力的扩展，尚未完整复刻腾讯文档。暂不包含实时多人合并编辑、跨工作簿公式、图表 / 透视表、附件字段、自动化规则、字段级权限和腾讯在线文档链接直连导入。Word 不保证页眉页脚、分页和复杂排版一致，图片不嵌入数据库；表格不保证宏、图表、合并单元格和全部 Excel 格式一致。XMind 只导入首个画布的树形主题，不保留关系线、贴图和原始布局。

## 构建与验证

```powershell
npm run build:mobile
node scripts/test-workspace.mjs
node scripts/test-avatar-color.mjs
node scripts/test-annotations.mjs
cargo test --offline --manifest-path src-tauri/Cargo.toml --lib
.\scripts\test-android-rpc.ps1
```

新增结构在 `sql/collaboration.sql` 的 `mindmaps` 表，重复执行安全；客户端使用时自动创建。没有重写已有表格或文档数据。Android 已编译 RPC 集成测试使用临时账号 / 内容验证权限、私有内容隔离、保存视图和删除保护，并在结束时清理测试数据。

Windows 浏览器自动化在此环境无法启动；DOM 交互测试不能替代真实浏览器布局检查。没有连接 Android 测试设备，真机软键盘、系统文件提供器、安装升级和触屏布局仍需验证。发布产物、SHA256 与实际完成的验证记录在 `release/manifest-0.4.0.json`。
