# Folinov Console 0.4.0

[Features and compatibility](features-0.4.0.md)

- 沟通新增成员组：按职位查看团队，点击头像查看公开资料与作品，排除私有文档和表格
- 智能表格新增九种字段、必填校验、记录表单、批量操作、多条件筛选、分组排序和保存视图
- 智能表格支持表格、看板、画廊和月历，支持分组拖动及数字字段合计
- 普通表格增加撤销重做、区域复制粘贴、分页、条件统计公式及插删行列引用调整
- 新增思维导图：主题编辑、折叠、换父主题、颜色备注、缩放、自动保存、撤销重做与导出
- 文档支持 DOCX/Markdown/TXT/HTML 导入，表格支持 Excel/CSV/ODS 并保留公式，导图支持 XMind/FreeMind/JSON/大纲导入
- 移动端管理员成员操作常显，支持新增、查看、编辑、密码重置、停用恢复及删除无协作历史的账号
- 智能表格实现常用功能，兼容范围和未实现功能见 releases/features-0.4.0.md

Android versionCode 15. 签名与旧版一致，可覆盖升级。
