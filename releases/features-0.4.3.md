# Folinov Console 0.4.3

修复 Windows 空闲重连后，文档历史、文件夹删除等操作统一显示“数据库操作失败”的问题。实际原因为 MySQL 错误 1267：SQLx 默认 utf8mb4_unicode_ci 连接与既有 utf8mb4_0900_ai_ci 表在 CAST 数字 ID 后比较发生冲突。每个新连接现在显式使用与数据库一致的规则，保留一个连接及空闲释放策略，不更改既有内容。

修复桌面端统一回收站路由及删除拦截的位置，确保恢复接口、删除锁定和已删除内容访问检查应用到全部业务请求。业务内容及其关联记录仍在数据库保留。

文档、表格使用左侧常驻目录与右侧内容区。侧栏可单击切换，也可直接将自己创建的内容拖到任意层级的文件夹。支持根目录、面包屑和子文件夹投放，目标高亮及移动完成反馈；文件夹右键提供重命名和带数量确认的逻辑删除。

本地草稿与服务器内容完全相同时自动撤下提示，成功保存后即时清除提示；不依据版本号或时间猜测草稿是否可以丢弃。未同步的草稿可以预览、另存私有副本；在线且共享版本未变化时，可继续编辑原文档。离线副本不用于确认草稿已经同步。

修复 Tiptap 切换可编辑状态时默认触发 update 事件的问题，打开文档不再发起自动保存。此前数据库出错时，单纯打开文档也可能被写为未保存草稿。

Android versionCode 18，沿用既有签名。与旧版保持相同数据库结构，无需转换文档或表格。Windows 仍使用自定义协议加载内置工作台。

验证记录将在安装包完成后写入 release/manifest-0.4.3.json。实体打印机和 Android 真机操作未在本环境验证。
