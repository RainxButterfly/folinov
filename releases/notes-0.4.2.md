# Folinov Console 0.4.2

[Features and compatibility](features-0.4.2.md)

- 修复电脑端进入文档、新建表格与读取版本历史时的闪退，增加单次操作异常保护
- 文档和表格改为桌面式文件夹与文件卡片，支持双击进入、返回上级和拖拽归档
- 文件夹右键支持重命名和删除，删除前显示包含数量，锁定内容阻止删除
- 新增文档/表格删除锁定与统一回收站，业务删除保留数据库内容及关联记录，可恢复
- 智能表格记录、字段及导图主题支持删除后恢复，历史快照归档保留
- 打印/PDF 与 HTML 导出只呈现工作室 Logo、名字和文档内容，Windows PDF 不带 localhost 和默认页眉页脚
- 降低桌面端连接占用，最多一个数据库连接，空闲及时释放

Android versionCode 17. 签名与旧版一致，可覆盖升级。
