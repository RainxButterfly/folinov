# Folinov Console 0.4.3

[Features and compatibility](features-0.4.3.md)

- 修复 Windows 数据库重连后字符规则冲突（1267）导致文件夹删除、文档历史等操作失败
- 修复只打开文档也触发自动保存，继而错误留下未保存草稿的问题
- 草稿支持预览、继续编辑原文档和另存私有副本；确认已同步及保存成功后及时撤下提示
- 文档和表格改进为常驻目录与内容区，支持拖到侧栏任意层级及面包屑，投放目标清晰高亮
- 修复 Windows 回收站恢复路由，统一执行删除锁定与已删除内容访问检查，保留数据库内容
- 数据库错误保留错误编号，区分字符规则、字段读取和连接等待问题

Android versionCode 18. 签名与旧版一致，可覆盖升级。
