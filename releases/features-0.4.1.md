# Folinov Console 0.4.1

Windows 与 Android 同步更新，Android versionCode 为 16，使用与 0.4.0 相同的正式签名，可覆盖升级。

- 文档和表格新增「权限与分类」：拥有者分别授权修改、删除，支持指定成员，并控制独立留言区。公开内容默认只读，管理员保留管理权限。
- 文档和表格支持项目文件夹、多级目录、重命名和批量归档。整理目录保留原有协作权限。
- 普通文档新增字体、字号、文字颜色、图片、查找替换、HTML 导出和打印/PDF 入口。Markdown 导出保留表格、嵌套列表和待办状态。
- 智能表格新增统计概览、分组统计图、批量修改、组合筛选和日历日期字段选择。
- 思维导图完善 XMind 多工作表、游离分支、FreeMind 富文本和 JSON 大纲导入，完整展示长标题，并增加分支配色、适应画布、查找高亮。
- 文档、表格、导图支持版本历史预览、命名、导出和恢复。恢复先备份当前内容，保留现有权限、可见范围与分类。
- 新增保存版本校验，拦截过期保存；冲突时保留本地修改，支持另存私有副本、导出备份，以及重新打开后恢复失败草稿。
- 三类内容列表支持导入 Folinov 版本与草稿 JSON 备份，导入为私有副本。

版本历史每项最多保留 20 个版本、5 MB 快照；连续自动保存按阶段保留，重要节点可手动命名。只读成员不能查看文档和表格的历史草稿。重启后草稿恢复依赖本机副本存储已开启且可写。

版本号检查与共享更新提示用于防止覆盖，不提供实时内容合并或协同光标。完整 Word 排版、多工作表工作簿、透视表、智能字段关联及导图关系线、概要仍未实现。导图导入保留文字、树形结构、备注及部分颜色，不保证完全保留第三方软件版式。

首次访问相关功能时，客户端按现有机制从 sql/collaboration.sql 创建新增表。新版保存协议需要正确版本号，建议团队两端同步升级。旧版客户端没有这项保护，不能替代新版的协作行为。

发布前验证：TypeScript 生产构建、99 项功能断言、25 项编译后的安卓接口离线校验、7 项批注定位、15 项头像颜色校验、浏览器回归、Windows custom-protocol 生产构建、Android assembleRelease/lintRelease、APK 正式签名与工作台资源一致性。

本次执行环境拒绝数据库网络连接，因此真实数据库迁移、多账号联调与实际安装设备测试没有完成。下载源完整性及应用内更新记录状态以发布清单和发布结果为准。
