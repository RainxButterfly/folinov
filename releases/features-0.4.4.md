# Folinov Console 0.4.4

修复文件夹内创建文档/表格、修改分类和再次拖动时出现“数据字段读取失败（0）”的问题。MySQL 在预处理协议中将 LONGTEXT 上的 JSON_UNQUOTE 表达式报告为 LONGBLOB；旧代码尝试读成 Rust String。现在直接读取 metadata 文本后解析路径，避免表达式类型转换；包含已删除文件夹的数据库也能正确执行归档。

新建空白文档、模板文档、普通表格、智能表格和文件导入统一在一次事务中写入初始内容与当前文件夹。归档校验或写入失败会回滚新建内容，不再留下位于根目录的半成品。Windows 和 Android 均采用该规则。

文档内表格增加鼠标悬停边缘的“＋”行列插入入口，支持按实际单元格边界定位；表格上方和下方均提供文字段落入口，包括文档首个元素就是表格的情况。原工具栏操作继续可用。

输入/粘贴的 Markdown 提供右上角转换提示，确认后才排版；取消、关闭立即撤下，未操作时 10 秒自动关闭。关闭编辑器默认 Markdown 粘贴/输入转换规则，避免在确认前改变原文。转换可以通过编辑器撤销恢复。

打印入口改为独立打印机图标，继续生成无默认页眉页脚的品牌 PDF 并打开后续打印。保留工作室 Logo、工作室名称和正文。

补齐 Windows 后端关闭留言区的校验。创建、移动、逻辑删除、恢复及版本检查保留原权限与删除锁定。

本轮验收使用工作区内独立 MySQL 8.0.38 实例、正式 SQLx 预处理协议及生产页面。测试覆盖全部页面固定调用接口，包含回收站已有文件夹、两次连续拖动、错误写入后的事务回滚、权限与版本冲突等状态。安卓使用实际编译 Kotlin 与 JDBC 预处理协议测试。业务数据库未用于清空或重建测试环境。

精确检查数量和结果见 release/manifest-0.4.4.json 及 .build-tools/acceptance-0.4.4.json。实体打印机和 Android 真机安装仍需设备验证；未把这两项标记为自动测试通过。
