## 发布新版本

1. 把新的安装包放进 `releases/`，文件名保持 `FolinovConsole-Setup-<版本>.exe`。
2. 提交并打 tag（例如 `v0.2.0`）推送到 GitHub。
3. 在 Folinov Console 的「设置 → 关于与更新 → 发布新版本」里填写版本号、主下载地址与镜像地址。
